# Bookline

Simple bookings, reminders and lost-money tracking for any small business: barbers, cleaners, tutors, mechanics, photographers, tailors, repair shops and more.

- **Live app:** open `index.html` (the home page of this site)
- **Demo with example businesses:** open `demo.html`

## What it does
- One diary for all bookings, with the next booking highlighted
- One-tap WhatsApp reminders with the message already written
- "Did they come?" check-in, with earnings and money lost to no-shows
- Customer list and a "bring them back" list for customers who stopped coming
- Service dropdown, so owners add and price their own services
- Works on any phone browser. Data stays on the user's own phone.

## Hosting
This is a plain HTML site with no build step. Publish it with GitHub Pages: Settings, Pages, deploy from the `main` branch, root folder.
